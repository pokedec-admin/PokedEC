## �🛠️ Technologies Open Source

Nous tenons à remercier les communautés Open Source qui ont créé les outils formidables sur lesquels repose cette application :

### Frontend
- **[Angular](https://angular.io/)** : Le framework web de Google pour bâtir des applications robustes.
- **[TypeScript](https://www.typescriptlang.org/)** : JavaScript typé pour un développement plus sûr.

### Backend
- **[Node.js](https://nodejs.org/)** : Environnement d'exécution JavaScript côté serveur.
- **[Express](https://expressjs.com/)** : Framework web minimaliste et flexible pour Node.js.
- **[PostgreSQL](https://www.postgresql.org/)** : La base de données relationnelle open source la plus avancée au monde.
- **[node-postgres (pg)](https://node-postgres.com/)** : Client PostgreSQL pour Node.js.

### Infrastructure
- **[Docker](https://www.docker.com/)** : Plateforme de conteneurisation pour déployer l'application partout.
- **[Nginx](https://nginx.org/)** : Serveur web haute performance et reverse proxy.

## 📊 Données & Images

- **[PokéAPI](https://pokeapi.co/)** : L'API RESTful gratuite qui fournit toutes les données Pokémon (noms, stats, sprites) utilisées dans cette application. Une ressource inestimable pour la communauté !
