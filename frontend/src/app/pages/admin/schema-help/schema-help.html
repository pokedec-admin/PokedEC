Exclusive Category System

                    
    
                        
  • Admin Side: Dropdown to select ONE category
                            (Normal/Legendary/Mythical/Ultra Beast) in /admin/pokemon-categories
    • 
                        
  • User Side: Only admin-defined category is visible/toggleable in Pokedex
                        
    • 
                        
  • Backend: Toggle endpoint ensures mutual exclusivity
    • 
                        
  • Propagation: Admin changes automatically update user Pokedex entries
    • 
                    


                    
Trade System

                    
    
                        
  • Users mark variants as "for trade" using trade flags
    • 
                        
  • GET /pokedex/trade-available shows Pokemon from other trainers
    • 
                        
  • Trade flags are mutually exclusive for exclusive categories
    •
